1. Data Types & Variables

  1. Create variables for your name, age, and city. Print all three values using console.log().
  2. Create one variable for your age and check its data type using typeof.
  3. Create a string, number, boolean, null, and undefined variable. Print the typeof of each.
  4. Store a person's name and whether they are logged in. Print both values and their data types.
  5. Create a variable for a product price and another for product availability. Print their values and types.
  6. Create an undefined variable without assigning any value. Check its type using typeof.

2. Objects — Basic Practice

  1. Create a student object with name, age, course, and isPresent. Print the complete object.
  2. Create a laptop object with brand, color, ram, and price. Print the brand and price.
  3. Create a user object with name, email, and isLoggedIn. Print each property separately.
  4. Create a mobile phone object with brand, model, price, and isAvailable. Print a suitable message using its values.
  5. Create a product object with name, price, and stock. Check whether the product is in stock using a condition.
  6. Create a movie object with title, rating, and isAvailable. Print the movie information.

3. Arrays — Basic Practice Only

  1. Create an array containing 5 student names. Print the complete array.
  2. Create an array containing 5 numbers. Print the first element and the last element.
  3. Create an array containing three product names. Print the array and one selected product.
  4. Create an array containing different basic data types such as a number, string, and boolean. Print the array.
  5. Create an array containing 4 prices. Print any two prices from the array.
  6. Create an array of three colors. Print the first color and the second color.

4. Arithmetic Operators

  1. Create two numbers and calculate their sum using the + operator.
  2. Create two numbers and calculate their difference using the - operator.
  3. Create two numbers and calculate their product using the * operator.
  4. Create a total bill amount and number of people. Calculate how much each person should pay using /.
  5. Create a number and check its remainder when divided by 2 using the % operator.
  6. Calculate the total price of 4 notebooks if one notebook costs 75.
  7. Calculate the final amount after spending 350 from a balance of 1000.
  8. Use the ** operator to calculate 2 raised to the power of 5.

5. Assignment Operators

  1. Create score = 10. Increase the score by 5 using an assignment operator and print the result.
  2. Create balance = 1000. Decrease the balance by 250 using an assignment operator.
  3. Create number = 5. Multiply it by 3 using an assignment operator.
  4. Create total = 100. Divide it by 4 using an assignment operator.

6. Comparison & Equality

  1. Create two numbers and check whether the first number is greater than the second.
  2. Create an age variable and check whether the age is greater than or equal to 18.
  3. Compare '10' and 10 using ==. Print the result.
  4. Compare '10' and 10 using ===. Print the result.
  5. Create two variables with the same value and check whether they are strictly equal using ===.
  6. Create two different numbers and check whether they are not equal using a comparison operator.

7. Type Conversion

  1. Convert the string '100' into a number and add 50 to it.
  2. Convert the number 500 into a string and check its type using typeof.
  3. A product price is stored as the string '999'. Convert it to a number and calculate its final price after adding 100.
  4. Convert a numeric string into a number and compare the converted value with another number using ===.
