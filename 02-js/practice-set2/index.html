JS Practice 02 (Functions)

Part 1: Function Basics

  1. Create a function greet() that prints 'Welcome to Code Ki Pathshala'.
  2. Create a function sayHello() and call it three times.
  3. Create an arrow function that prints your name.
  4. Create a function showCity() that prints your city.
  5. Create a function showCourse() that prints your course.

Part 2: Parameters & Arguments

  1. Create printName(name) and print the name.
  2. Create printAge(age) and print the age.
  3. Create printCity(city) and print the city.
  4. Create greetUser(name) that prints Welcome + name.
  5. Call the same function with 5 different names.

Part 3: Conditions Inside Functions

  1. Create checkAge(age) that checks voting eligibility.
  2. Pass 5 different ages to the function.
  3. Create checkDriving(age) that checks driving eligibility.
  4. Create checkPass(marks) that prints Pass or Fail.
  5. Create checkEvenOdd(number).

Part 4: Return Keyword

  1. Create sum(a,b) and return the result.
  2. Create subtract(a,b) and return the result.
  3. Create multiply(a,b) and return the result.
  4. Create divide(a,b) and return the result.
  5. Store the returned value in a variable and print it.

Part 5: Operators + Functions

  1. Create calculateBill(price, quantity).
  2. Create calculateDiscount(price).
  3. Create calculatePower(a,b) using **.
  4. Create checkRemainder(number).
  5. Create compareNumbers(a,b) and print the larger number.

Part 6: Objects + Functions

  1. Create a student object and print the student's name using a function.
  2. Create a laptop object and print its brand using a function.
  3. Create a user object and print the email using a function.
  4. Create a product object and print its price.
  5. Create a movie object and print its title.

Part 7: Arrays + Functions (Basic)

  1. Create an array of names and print the first name using a function.
  2. Create an array of colors and print the second color.
  3. Create an array of prices and print the first price.
  4. Pass an array element to a function and print it.
  5. Create an array of cities and print any city.

Part 8: Real-World Problems

  1. Create checkLogin(isLoggedIn) and print Login Success or Login Required.
  2. Create checkAdmin(isLoggedIn, isAdmin).
  3. Create checkTemperature(temp) and print Hot, Normal or Cold.
  4. Create checkStock(stock) and print Product Available or Out of Stock.
  5. Create checkDelivery(amount) and print Free Delivery or Delivery Charges.
